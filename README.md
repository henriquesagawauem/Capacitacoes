## 📖 Sobre o repositório

Este repositório reúne os **materiais, exercícios e projetos** desenvolvidos ao longo das **capacitações do PET Informática (UEM)** — um programa de educação tutorial focado em formar alunos com base sólida em programação, lógica computacional e boas práticas de desenvolvimento.

Cada pasta representa uma capacitação concluída ou em andamento, contendo o código produzido, anotações e desafios propostos durante os encontros.

> 💡 O objetivo deste repositório é documentar minha jornada de aprendizado dentro do PET, servindo tanto como portfólio quanto como material de consulta futura.

## 💻 Capacitação em C

A **Capacitação em C** é o ponto de partida da trilha de formação do PET Informática, com foco em:

- 🧠 Lógica de programação e estruturas de controle
- 📦 Ponteiros, alocação dinâmica de memória e manipulação de structs
- 📚 Estruturas de dados básicas (listas, pilhas, filas)
- 🧩 Resolução de exercícios e desafios práticos
- 🛠️ Boas práticas de organização e legibilidade de código

📁 Acesse a pasta [`Capacitação em C`](./Capacitação%20em%20C) para conferir os exercícios e projetos desenvolvidos.

## 🎯 Sobre o PET Informática

<div align="center">
<img src="https://img.shields.io/badge/Programa%20de%20Educa%C3%A7%C3%A3o%20Tutorial-PET-orange?style=for-the-badge" />
</div>

O **PET Informática** é um grupo do Programa de Educação Tutorial vinculado ao curso de Ciência da Computação e Engenharia de Software da **UEM**, que promove atividades de ensino, pesquisa e extensão. As capacitações são um dos principais pilares do programa, oferecendo trilhas de aprendizado estruturadas para o desenvolvimento técnico dos alunos participantes.
